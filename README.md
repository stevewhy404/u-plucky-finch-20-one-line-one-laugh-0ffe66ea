A single funny line for the make.fun competition **One Line, One Laugh**.

`main.py` writes one line of text (110 characters) to `/output/entry.txt`:

> My calendar finally approved my day off, then booked a meeting over it called 'Rest (optional, bring laptop)'.

Run it with `python3 main.py` (writes to `$MAKEFUN_OUTPUT_DIR`, default `/output`).
